# Rumies

## Project Overview

This is a multi-page HTML/CSS project (the Rumies roommate-matching platform). When making CSS changes, check all HTML files for consistency — styles are defined inline per page but follow shared conventions. Always verify mobile responsiveness after any layout change.

**Pages:**
- `rumies-landing.html` — public landing page
- `rumies-onboarding.html` — sign-up flow
- `rumies-dashboard-søgende.html` — seeker dashboard
- `rumies-dashboard-udlejer.html` — landlord dashboard
- `rumies-matches.html` — match browsing
- `rumies-chat.html` — messaging
- `rumies-profile.html` — profile view

## Workflow Preferences

When the user describes a UI design preference, ask for clarification before implementing if there are multiple possible approaches. Prefer showing a brief plan before making extensive edits.

## Local Development

Use `python -m http.server 8080` to serve the project locally. Port 3000 is often unavailable; default to 8080.
